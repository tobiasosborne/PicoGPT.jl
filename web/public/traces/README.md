# Frontispiece traces

One SVG per chapter opening, named after the chapter slug, plus the cover:

    cover.svg  prologue.svg  task.svg  vectors.svg  energies.svg  surprise.svg
    attention.svg  block.svg  pulling-back.svg  learning.svg  speaking.svg  epilogue.svg

The page picks a file up automatically (no code change). Until it exists the slot
is omitted on the web and left blank in print. Drawing rules (palette tokens,
stroke widths, viewBox, no text, transparent background): DESIGN.md §9 "Traces".
